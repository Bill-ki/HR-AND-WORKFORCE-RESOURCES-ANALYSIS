# HR-AND-WORKFORCE-RESOURCES-ANALYSIS

## Project Overview
This project examines workforce structure and employee-related metrics within a retail and distribution business. The analysis focuses on headcount, departmental distribution, salary patterns, payroll expenditure, employee tenure, and management structure.

## Analysis Performed
- Analysed employee distribution across departments.
- Evaluated annual payroll and salary distribution.
- Calculated average salary and employee tenure.
- Examined departmental workforce composition.
- Reviewed management structure and reporting relationships.

## Key Findings
- The dataset contains 36 employees across seven departments.
- Average employee tenure is approximately 6.7 years.
- Departmental salary and headcount patterns provide insight into workforce distribution and payroll allocation.

## Tools & Technologies

- Excel Charts & Dashboards

## Data Note
The analysis uses a synthetic practice dataset. Employee tenure should not be interpreted as an attrition or retention rate.
